# rpack

Архиватор со смешиванием контекстов (семейство PAQ/lpaq), на чистом Rust без зависимостей.

Каждый бит предсказывают 11 контекстных моделей (порядки 0–8, слова, разреженные контексты), каждая даёт два входа
плюс вход «истории битов»; модель повторов находит длинные совпадения. Всё это смешивают три нейронных смесителя
(выбор весов по текущему байту, по длине совпадения и по предыдущему байту), второй слой смешивает их выходы,
три SSE-ступени уточняют вероятность, дальше арифметический кодер. Только целочисленная арифметика, поэтому
распаковка на другой машине даёт тот же результат.

```
rpack c файл выход        сжать файл
rpack d вход выход        распаковать
rpack a архив пути...     упаковать файлы и папки (сплошной архив, файлы с одним расширением идут подряд)
rpack x архив папка       распаковать архив (пути с .. и абсолютные отвергаются)
rpack bench файлы...      сравнить с gzip/bzip2/xz и проверить распаковку побайтно
```

## Замеры (байты, меньше — лучше)

| файл | размер | gzip -9 | bzip2 -9 | xz -9e | rpack |
|---|---|---|---|---|---|
| англ. текст (документация vim) | 467 636 | 147 820 | 116 930 | 122 084 | **95 827** |
| русский текст в js | 442 034 | 92 375 | 54 253 | 70 604 | **50 466** |
| json-подобные данные | 192 421 | 56 281 | 43 663 | 47 268 | **36 372** |
| исполняемый файл | 331 776 | 161 449 | 158 275 | 135 696 | **124 135** |
| 32 js-файла, папка целиком (rpack a / tar+xz) | 1 943 423 | | | 357 316 | **264 869** |
| уже сжатый .tgz | 396 768 | 396 869 | 399 016 | 396 856 | 396 847 |

Что стоит знать честно:
- Сжатое не сжимается: на .tgz выигрыша нет, это закон Шеннона, а не недоработка.
- Платим скоростью: примерно 0,3 МБ/с и в ту, и в другую сторону, и около 100–400 МБ памяти на крупных файлах. xz на порядок быстрее.
- Это один поток без многопоточности; формат пока не зафиксирован и может поменяться между версиями.
- Замеры на моих файлах. На ваших данных проверьте `rpack bench`.
